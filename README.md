Features:
 - Volume Control
 - Brightness Control
 - System info display
 - Modular Script System
 - Terminal UI via gum
 -

Dependencies: 
 - Gum           (UI)
 - pactl         (Audio Control)
 - wpctl         (Audo Control)
 - brightnessctl (Brightness Control)

  To install (pacman)
   - sudo pacman -S gum brightnessctl pactl wpctl
