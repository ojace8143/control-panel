Features:
 - Volume Control
 - Brightness Control
 - System info display
 - Modular Script System
 - Terminal UI via gum
 - Password Generator

Dependencies: 
 - Gum           (UI)
 - pactl         (Audio Control)
 - wpctl         (Audo Control)
 - brightnessctl (Brightness Control)
 - cpupower  (CPU Power and Performance Tweaks)

  To install (pacman)
   - sudo pacman -S gum brightnessctl pactl wpctl cpupower

Tips:
 - Make an alias of conrol_panel.sh for easy access
