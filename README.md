Features:
 - Volume Control
 - Brightness Control
 - System info display
 - Modular Script System
 - Terminal UI via gum
 - Password Generator

Dependencies: 
 - Gum           (UI)
 - pactl         (Audio Control)
 - wpctl         (Audo Control)
 - brightnessctl (Brightness Control)
 - cpupower  (CPU Power and Performance Tweaks)

  To install (Run in control_panel)
    - source ./.install_dependencies.sh

Tips:
 - Make an alias of conrol_panel.sh for easy access
 - Run .install_dependencies.sh to ensure all features work
